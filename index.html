運営者本人の業務を支援するアプリ

Daily Gmail

不動産メールを整理し、
物件と買いニーズの確認を支援します。

Daily Gmail は、運営者本人が許可した Google アカウントの Gmail を読み取り、不動産関連メールの受付・情報整理を行う業務補助アプリです。物件情報と買いニーズの照合・紹介候補の確認を支援する Daily システムの入口として利用します。

利用者は運営者本人に限定しています。
このページから第三者が利用登録することはできません。現在は段階的な検証・復旧中であり、登録から照合・通知までの全工程が自動稼働しているという案内ではありません。

Gmail は読み取り専用

使用する権限は gmail.readonly です。本アプリからメールの送信・削除・移動、ラベルの変更、既読・未読の変更は行いません。

本人の業務整理に限定

メールの受付、重複処理の防止、原文への参照、必要な物件・買いニーズの整理と照合支援に利用します。公開用の物件掲載サイトやメール配信サービスではありません。

どのように情報を扱うか

通常の自動受付では、メールの識別情報・件名の照合用の値・分類などを記録します。必要なメールの原文確認や、承認した範囲の解析では、本文・添付資料等を扱う場合があります。Neon による記録の保存、GitHub Actions による処理実行、必要な場合の OpenAI API による解析支援は、下記の方針に従います。

メール本文・物件情報・買いニーズ・認証情報は、この公開サイトには掲載しません。

取得・利用・保存・削除の方針を読む

Google ユーザーデータの取扱い

Daily Gmail は、Google API Services User Data Policy（Limited Use 要件を含みます）に従って、Google API から取得した情報を取り扱います。広告配信・データ販売・汎用 AI モデルの学習のために利用・提供することはありません。
