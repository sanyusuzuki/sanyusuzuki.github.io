Daily Gmail

プライバシーポリシー

本ポリシーは、運営者本人が利用する Daily Gmail の Google アカウント連携、情報の処理、およびこの説明サイトに適用します。不特定多数のユーザー向けのサービスではありません。

現在の自動受付と、個別に承認して実行する原文確認・解析を区別して記載しています。公開ページの設置自体は、停止中の処理の再開やデータ送信への同意を意味しません。

1．取得・参照する情報

  • 接続・認証情報：接続する Google アカウントの確認用情報、OAuth の認可に必要な情報、アクセストークン・更新用トークン。
  • 通常の自動受付：Gmail のメッセージ ID・履歴 ID、件名、添付ファイル名など。受付台帳には ID、件名の照合用の値（ハッシュ）、分類、処理状態などを記録し、この受付処理ではメール本文や添付ファイルの内容を台帳に保存しません。ハッシュ等も本ポリシーの保護対象です。
  • 必要なメールの原文確認・整理：運営者が実行を認めた対象について、件名、送信者・宛先、受信日時、本文、添付資料、資料の参照情報と、それらから整理した物件条件・買いニーズ等を扱う場合があります。

Gmail の読み取り権限は本文や添付資料等へのアクセスを含む権限です。実際の処理は目的に必要な範囲に限定します。Google アカウントのパスワードを本アプリが収集することはありません。

2．利用目的

不動産関連メールの受付・分類、重複処理の防止、原文・資料との対応確認、物件情報と買いニーズの整理・照合、運営者向けの結果確認、障害の調査・復旧のために利用します。Gmail と無関係な目的のデータ収集や、無関係な個人の行動分析には利用しません。

照合・解析結果は運営者が確認するための補助情報です。本アプリから取引先へメールを自動送信したり、売買の判断を自動で確定したりすることはありません。

3．権限と Gmail の状態

使用する Gmail 権限は https://www.googleapis.com/auth/gmail.readonly です。メール送信・削除・移動、ラベル変更、既読・未読変更の権限は要求せず、本アプリからこれらの変更を行いません。

4．保存・処理先と外部サービス

Google
Gmail データの読取りと OAuth 認証に利用します。元のメール・添付資料は Gmail 内に残ります。
GitHub
非公開のコード管理、GitHub Actions での処理実行、Secrets による認証情報の管理に利用します。承認した処理では必要な情報を実行環境内で扱います。この説明サイトの公開用ファイルと、業務用のコード・設定・記録は分離します。
Neon
非公開のデータベースに、受付記録、必要な整理済み情報、出典参照、処理結果を保存するために利用します。
OpenAI API
運営者が利用を認めた解析処理に限り、物件条件・買いニーズ・必要な抜粋等を送信して、整理・照合の確認を補助する場合があります。通常の Gmail 自動受付そのものは AI を呼び出しません。API の応答保存を無効にする設定を使用しますが、これを提供者の安全管理ログ等も含む「一切保存されない」状態とは表現しません。

外部サービスへのデータ移転は、上記の機能に必要な範囲と運営者の承認に限ります。承認していない別の AI・広告・販売サービスへ情報を送信しません。処理・保管に日本国外の設備が利用されることがあります。提供者側の処理には各サービスの規約・データ管理方針も適用されます。

運営者が別途 ChatGPT 等に情報を直接入力する操作は、この Gmail OAuth アプリの自動処理とは別です。本アプリから取得した情報を別サービスへ渡す場合も、本ポリシーと Google の利用制限を守る必要があります。

5．利用・共有の制限

Daily Gmail は、Google API Services User Data Policy（Limited Use 要件を含みます）に従います。Google API から取得した情報とその派生情報を、広告配信・データ販売・信用判断や融資判定・汎用 AI モデルの学習のために利用・提供しません。

人による閲覧は、運営者本人の確認、または運営者が明示的に認めた個別の確認・必要な障害調査等に限定します。サービス提供に必要な処理、セキュリティ確保、適用法令への対応など、Google の方針で認められる範囲を除き、第三者へ移転しません。

6．保持と削除

情報は、業務上の利用、重複処理の防止、出典確認、障害復旧に必要な期間に限って保持し、不要になった情報や重複する記録を運営者の確認に基づき整理・削除します。現在、一律に「翌日」または「3年後」にすべて自動で完全削除される仕組みを保証するものではありません。

利用停止・データ削除は、下記の連絡先へ依頼できます。対象と本人確認を行ったうえで、アプリが管理する該当データ・認証情報について対応します。提供者のバックアップや安全管理ログ等の残存期間は各サービスの方針に従います。アプリ側の削除によって、Gmail 内の元のメールや添付資料を削除することはありません。

7．安全管理

OAuth 認証を利用し、秘密情報を公開用ファイルに含めません。業務用コード・設定・記録へのアクセスを限定し、通信は HTTPS 等の暗号化された経路を使用します。公開用のページへ、メール本文・業務データ・認証トークンを表示・埋込み・アップロードしません。

8．連携の解除

Google アカウントの第三者との接続設定から、Daily Gmail のアクセス権を取り消すことができます。解除後は新たな Gmail データの読取りができなくなります。すでに保存した記録の削除は別の対応となるため、削除を希望する場合は連絡先へお知らせください。

9．この説明サイトについて

このサイトには入力フォーム、Google ログインボタン、広告、アクセス解析スクリプトを設置していません。このサイトにアクセスしただけで Gmail の認証や読取りが実行されることはありません。

公開先として利用する GitHub Pages では、サイトの配信・安全管理等のため、GitHub が IP アドレス等のアクセス情報を処理する場合があります。詳細はGitHub のプライバシーステートメントをご確認ください。
